# Rooms Implementation Plan

> **For agentic workers:** Read `docs/rooms.md` (the spec) first. Then implement the tasks in order, one at a time, test-first, exactly as their steps say. Tick each `- [ ]` box in this file when its step is done. Don't start a task until `make test` is green and the previous task is committed. If a step conflicts with the code you find, stop and say so instead of guessing.

**Goal:** Group conversations ("rooms") where several characters and the user talk. Turns pass between characters by @mention, and a discretion-driven share gate decides which private facts each character brings up.

**Architecture:** A room is stored as one conversation per member, plus one for the user (`character_id = 'me'`, the transcript). Fan-out writes each utterance into the copy of every member who heard it, so every existing per-character query (search, close, forget) works unchanged and isolation stays in the store. `Runner.RoomTurn` orchestrates the speakers and calls the existing `Runner.Turn` once per character turn. In room mode `Turn` gates memory through one `CallStructured` call.

**Tech Stack:** Go 1.x, pgx/Postgres (numbered SQL migrations), Vue 3 + TS frontend, `llm.NewFake` for tests, `storetest.New` for Postgres tests.

**Spec:** `docs/rooms.md`

## Global Constraints

- Default `discretion`: 5. Valid range: 0–10. Fixed bands: 0–3, 4–7, 8–10, with the exact wording from `docs/rooms.md` §5.
- At most 4 character turns per user message (`maxRoomTurns = 4`).
- A room has ≥2 distinct characters, all known ids. `me` is never listed as a member.
- Conversation ids: `room:<roomID>:<characterID>` and `room:<roomID>:me`. A room id is 8 lowercase hex characters, so ids stay within `conversationIDRe` (`^[A-Za-z0-9:_-]{1,80}$`).
- The gate fails closed: any error shares nothing.
- `told_by` is derived server-side from the source message's `speaker`, never from model output.
- No change to 1:1 chat behavior. Every existing test stays green.
- Don't run `go test ./...`. Use `make test` (the Makefile filters out `frontend/node_modules`).

## Review Focus

1. **A user message that @mentions a non-member, or nobody, in a new room:** the first member answers. Test: `TestNextSpeaker` cases.
2. **A character replies `@ria` while Ria is the current speaker (self-mention):** the chain ends instead of looping. Test: `TestNextSpeaker` "self mention ends".
3. **The gate model returns ids it was never offered (forged `f999`):** they're ignored, never loaded. Test: `TestGateRejectsUnknownIDs`.
4. **The gate call errors or returns prose:** the turn still runs, with no private facts. Test: `TestRoomTurnGateFailsClosed`.
5. **The nightly close runs over a day containing a `me` transcript copy:** `me` is skipped, not closed. Test: `TestCloseSkipsMeCopy` in Task 8.

### Task 6: Room orchestration

**Files:**
- Create: `assistant/room.go`
- Test: `assistant/room_test.go`

**Interfaces:**
- Consumes: `Turn` with `Speaker`, `Names` and `Listeners`, `Result.Text` (Tasks 3 and 5), `store.Room`, `RoomConversationID` (Task 1)
- Produces:
  - `const maxRoomTurns = 4`
  - `type Member struct { ID, Name string; Character Character }`
  - `func NextSpeaker(text string, members []Member, current string) string` returns the first @mentioned member (id or name, case-insensitive, `@` followed by the whole token) that isn't `current`, or `""`.
  - `type RoomRequest struct { Room store.Room; Members []Member; Input string }`
  - `func (r *Runner) RoomTurn(ctx context.Context, req RoomRequest, emit func(Event)) error`
  - `Event.Type` gains `"speaker"`, with `Name` = the character id, emitted before each character's turn.

**RoomTurn algorithm**, under `r.lockFor("room:"+id)`:

1. `first := NextSpeaker(input, members, "")`. If that's empty, use the latest message with a character `speaker` in the `me` copy. If there isn't one, use `members[0]`.
2. Store the input in the `me` copy (role `user`, speaker `me`) and in every member copy except `first`'s.
3. Loop up to `maxRoomTurns`:
   - `emit(speaker)`
   - `Turn` on the speaker's copy, with `Input` = the raw text, `Speaker` = who spoke, `Listeners` = the other members' names
   - `next := NextSpeaker(res.Text, members, speaker)`
   - store `res.Text` in the `me` copy (role `assistant`, speaker = the character) and in every other member copy except `next`'s (role `user`, speaker = the character)
   - stop if `next == ""` or `res.Text == ""` or there was an error
4. Return the first error.
